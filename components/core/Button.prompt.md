Primary action component for BIOBRZ. Always uppercase with wide letter-spacing — a key brand signal.

```jsx
<Button variant="primary">Fale Conosco</Button>
<Button variant="accent" size="lg">Solicitar Diagnóstico</Button>
<Button variant="outline">Saiba Mais</Button>
<Button variant="ghost" size="sm">Ver Todos</Button>
<Button variant="dark">Entrar em Contato</Button>
<Button disabled>Indisponível</Button>
```

**Variants:**
- `primary` — green fill, white text. Default for most actions.
- `accent` — gold fill, black text. High-emphasis CTA (e.g., hero section).
- `outline` — transparent with green border. Secondary action on light bg.
- `outline-light` — transparent with white border. Use on green/dark backgrounds.
- `ghost` — no border or fill. Tertiary, inline links.
- `dark` — black fill, white text. For light sections needing contrast.

**Sizes:** `sm` (12px), `md` (14px, default), `lg` (16px)
